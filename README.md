# Мультастудия

Студия для создания мультфильмов на Android.

## Как скачать APK
1. Открой вкладку **Actions** в этом репозитории.
2. Выбери последний запуск «Сборка APK» с зелёной галочкой.
3. Внизу в разделе **Artifacts** скачай `Multastudia-APK` (это zip, внутри `Multastudia.apk`).

## Этап 1 (сейчас)
- Кисть (размер, прозрачность, сглаживание, цвет), ластик, лассо (двигать/крутить/масштабировать двумя пальцами, отразить, штамп), заливка, текст
- Ещё: пипетка, линия, прямоугольник, овал, сетка
- Слои: видимость, непрозрачность, порядок, переименование
- Кадры: добавить, дублировать, копировать/вставить, сдвинуть, удалить, длительность (×N)
- Калька (до/после), проигрывание, скорость кадров
- Зум/поворот/перемещение двумя пальцами, рисование за холстом
- Вставка картинки, экспорт GIF, PNG-кадров и одного кадра
